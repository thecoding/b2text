b2text 设置

后端

默认 http://127.0.0.1:8765。先运行 b2text serve start。若指向远程机器，需后端支持 HTTPS/CORS 且 Chrome 已授予对应 host 权限。

转写文字层

也可以在播放页面板上按 A− / A+ 直接调整。

遮挡层

遮挡层默认只遮挡视频底部字幕区；按住遮挡条任意位置拖动可移动， 右下角手柄可调整大小（底边固定）。

快捷键

  • Ctrl/^ + Shift + → 下一句
  • Ctrl/^ + Shift + ← 上一句
  • Ctrl/^ + Shift + T 显示/隐藏转写文字
  • Ctrl/^ + Shift + O 显示/隐藏遮挡层

macOS 用 Control（^），Windows/Linux 用 Ctrl；不使用 Alt/Option （macOS 上会输入特殊字符）。修改方式： chrome://extensions/shortcuts
